# PDF Công Vụ

Chuyển ảnh, văn bản, file Word sang PDF ngay trên điện thoại. Trình bày văn bản theo Nghị định 30/2020/NĐ-CP.

Mở: https://nguyenkhang2021zzz-a11y.github.io/pdf-cong-vu/

- Mọi xử lý chạy trên máy người dùng; không gửi tài liệu, ảnh hay nội dung văn bản đi đâu.
- iPhone: mở bằng Safari → nút Chia sẻ → "Thêm vào MH chính". Sau lần mở đầu dùng được khi không có mạng.
- Phông chữ Tinos (SIL Open Font License, xem fonts/OFL.txt).
